2. 登录接口

POST https://ehallmobile.xyc.edu.cn/api/v4/api/login（form-urlencoded，jQuery $.ajax）

字段值说明
userDevice学号 + 13位毫秒时间戳设备标识，风控相关
loginNamehex3DES(学号)
keyhex3DES(随机密钥, 主密钥)
passWordhex3DES(密码)
loginType2账密登录（短信=5）
validateCode—仅图形验证码启用时（该校 picCodeShow=0，关闭）

加密算法（复现自 app.js reEncrypt()）

rk = 随机 24 位 [A-Za-z0-9]                       // 每次登录生成
userName     = 3DES-ECB-PKCS7(学号,   rk)  → hex
userPassWord = 3DES-ECB-PKCS7(密码,   rk)  → hex
key          = 3DES-ECB-PKCS7(rk, 主密钥)  → hex
主密钥 = "dc651e062a92599aa1230153"               // 写死在门户 JS，24 字节

等价 CryptoJS 调用：CryptoJS.TripleDES.encrypt(plain, CryptoJS.enc.Utf8.parse(key), {mode: ECB, padding: Pkcs7})，ciphertext.toString() 即 hex。 Kotlin 实现：DESede/ECB/PKCS5Padding（PKCS5 对 8 字节块 = PKCS7），见 app/.../data/remote/CryptoUtil.kt。

响应

{"code":"200","token":"...","data":{"CASTGC":"...","JSESSIONID":"...","casUserInfo":{...}}}
code含义处理
200成功前端写 cookie：token、CASTGC、JSESSIONID，跳首页
1111新设备风控："您未在常用设备登录，需通过短信验证"需走短信登录（loginType=5）绑定设备后账密放行
402系统维护提示维护原因
1024锁定/待解锁（unclockFlag）待实测
