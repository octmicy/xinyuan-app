## 五、使用流程（生成后怎么进 App）

1. **生成**：每次生成 1 张集合图（一次出 6~7 个，多生成几次挑最满意的个体）。
2. **裁切**：用 PS / 醒图 / remove.bg 把单个图标抠出 → 统一裁成 **512×512 PNG**（透明底）。
3. **导航图标**：5 个小图标放进 `res/drawable-*`（或转 Vector），底部导航引用。
4. **App 封面图标**：大图标转 **Android 自适应图标**（前景层 432×432 + 背景色/图），
   Android Studio → New → Image Asset → Foreground Layer 导入。
5. 文字标签（课表/成绩…）**不要让 AI 画**（中文必乱码），一律由 App 代码渲染。
