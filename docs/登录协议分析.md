## 2. 登录接口

`POST https://ehallmobile.xyc.edu.cn/api/v4/api/login`（form-urlencoded，jQuery `$.ajax`）

| 字段 | 值 | 说明 |
|---|---|---|
| `userDevice` | `学号 + 13位毫秒时间戳` | 设备标识，风控相关 |
| `loginName` | hex | 3DES(学号) |
| `key` | hex | 3DES(随机密钥, 主密钥) |
| `passWord` | hex | 3DES(密码) |
| `loginType` | `2` | 账密登录（短信=5） |
| `validateCode` | — | 仅图形验证码启用时（该校 `picCodeShow=0`，关闭） |

### 加密算法（复现自 app.js `reEncrypt()`）

```
rk = 随机 24 位 [A-Za-z0-9]                       // 每次登录生成
userName     = 3DES-ECB-PKCS7(学号,   rk)  → hex
userPassWord = 3DES-ECB-PKCS7(密码,   rk)  → hex
key          = 3DES-ECB-PKCS7(rk, 主密钥)  → hex
主密钥 = "dc651e062a92599aa1230153"               // 写死在门户 JS，24 字节
```

等价 CryptoJS 调用：`CryptoJS.TripleDES.encrypt(plain, CryptoJS.enc.Utf8.parse(key), {mode: ECB, padding: Pkcs7})`，`ciphertext.toString()` 即 hex。
Kotlin 实现：`DESede/ECB/PKCS5Padding`（PKCS5 对 8 字节块 = PKCS7），见 `app/.../data/remote/CryptoUtil.kt`。

### 响应

```json
{"code":"200","token":"...","data":{"CASTGC":"...","JSESSIONID":"...","casUserInfo":{...}}}
```

| code | 含义 | 处理 |
|---|---|---|
| 200 | 成功 | 前端写 cookie：`token`、`CASTGC`、`JSESSIONID`，跳首页 |
| 1111 | **新设备风控**："您未在常用设备登录，需通过短信验证" | 需走短信登录（loginType=5）绑定设备后账密放行 |
| 402 | 系统维护 | 提示维护原因 |
| 1024 | 锁定/待解锁（unclockFlag） | 待实测 |

## 3. 已知接口表（app.js `GOLB_PORTS`）

登录认证相关：
- `login: /login`、`logout: /logout`
- `currentUser: /user/currentUser`
- `authLogin: /oauth/authLogin`（第三方系统免密跳转，SSO 入口候选）
- `oauthLogin: /oauth/login`、`oauthTokenLogin: /oauth/oauthTokenLogin`
- `loginForRsa: /loginForRsa`（今日校园客户端 rasInfo 场景）
- `VerifyCodeLogin: /oauth/VerifyCodeLogin`（短信验证码登录）
- `getVerifyCode: /oauth/getVerifyCode`（发送短信）
- `getValidateCodeImage: /sysInfo/getValidateCodeImage`（图形验证码，未启用）
- `oAuthList: /user/oAuthList`（统一认证应用列表候选）

## 4. config.js 关键配置

`picCodeShow=0`（无图形验证码）、`passwordShow=1`（密码加密）、`loginByMsg=1`（支持短信登录）、`firstLoginType=1`（默认账密）、`findType=phone`、微信登录 `wx65026618d660a198`、企业微信 `ww99a8321bac0aebbe`。
