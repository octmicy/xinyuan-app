# 新余学院校园助手 App — 开发方案 v1.0

> 对齐日期：2026-09-02　|　状态：需求已对齐，待搭环境开发

## 一、项目概述

为 新余学院（xyc.edu.cn） 开发一款安卓原生 App，替代"打开浏览器 → 登录移动门户 → 跳转教务系统"的繁琐流程，把**课表、成绩、考试、个人信息**等高频功能做成原生界面，ehall 其他应用做入口聚合。

| 项 | 决策 |
|---|---|
| 技术路线 | 原生 Kotlin + Jetpack Compose（Material 3 现代风） |
| 使用范围 | 先自用跑通，代码按可开源发布标准写（账号仅存本机、参数可配置） |
| 最低支持 | Android 8.0（API 26），覆盖绝大多数在用手机 |
| 参考项目 | 544r/wzu-assistant（架构模板）、paditianxiu/jxh_next（同省院校功能1:1）、wyvern1723/sachet（正方V9.0 API 最全参考，MIT） |

## 二、账号与登录链路（核心技术点）

**已确认的关键事实**：教务系统（zfjwxt）账号密码独立且不可获取，必须由门户（ehallmobile）登录后注入式跳转。

```
┌─ App 内置登录页 ──────────────────────────────┐
│  输入：学号 + 门户密码                          │
└──────────────┬───────────────────────────────┘
               ▼ ① POST 门户登录接口（密码可能需 RSA/SM2 加密，抓包确认）
     ehallmobile.xyc.edu.cn/mobile  ← 获得门户会话 Cookie
               ▼ ② 请求"教务系统"应用入口链接（门户/三方列表中获取）
               ▼ ③ 跟随 SSO 重定向链（302 数跳，携带一次性 ticket/token）
     zfjwxt.xyc.edu.cn/jwglxt  ← 落地拿到教务 JSESSIONID 会话
               ▼ ④ 用教务会话调用业务 API
     • 课表  /jwglxt/kbdy/...   （xnm=学年, xqm=学期）
     • 成绩  /jwglxt/cjcx/cjcx_cxXsKccjList.html?gnmkdm=N305005
     • 考试  /jwglxt/xskbcx/... （具体 gnmdm 以抓包为准）
     • 个人信息 /jwglxt/grxx/... 或 xsxxx
```

**待验证项（开发第一步）**：① 门户登录接口是否加密密码、是否有无验证码情况；② SSO 跳转链具体形态（CAS ticket 还是自研 token）；③ 会话有效期与自动续期方式。验证手段：真机浏览器 F12 / 抓包工具（HttpCanary 或电脑端 Fiddler），或直接用脚本模拟。

## 三、功能清单与优先级

| 优先级 | 功能 | 说明 |
|---|---|---|
| P0 | 登录 + 会话管理 | 门户登录、SSO 跳转、Cookie 本机加密存储（EncryptedSharedPreferences）、失效自动重登 |
| P0 | 课表查询 | 周视图网格、周次切换、今日高亮、单双周、课程颜色标记、本地缓存（离线可看） |
| P0 | 成绩查询 | 按学期筛选、加权 GPA / 学分自动计算 |
| P0 | 个人信息 | 学籍卡片：姓名、学号、学院专业班级、培养层次等 |
| P1 | 考试安排 | 时间/地点/座位号，本地缓存 |
| P1 | ehall 应用入口聚合 | 拉取 third 页应用列表做宫格首页，点击自动带会话内嵌打开 |
| P2 | 桌面小组件 | 今日课程 Glance Widget |
| P2 | 成绩更新提醒 | WorkManager 定期检查（默认 1~2 小时一次，克制频率防封禁），新成绩系统通知 |

## 四、技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| UI | Kotlin 2.x + Compose BOM + Material 3 + 动态取色 | 对齐决策 |
| 网络 | OkHttp + Retrofit（CookieJar 管理） | 正方接口是表单/JSON 混合，OkHttp 处理重定向链最可控 |
| 存储 | DataStore（配置）+ Room（课表/成绩缓存） | 离线秒开 |
| 安全 | EncryptedSharedPreferences 存账号密码 | 按可发布标准 |
| 小组件 | Glance | Compose 官方组件库 |
| 后台 | WorkManager | 成绩轮询 |
| 构建 | AGP 8.5+ / JDK 17 / minSdk 26 / targetSdk 34 | 对齐 wzu-assistant |

## 六、风险与应对

| 风险 | 应对 |
|---|---|
| 门户登录密码加密/风控未知 | M1 优先抓包验证；必要时 WebView 完成首次登录、Cookie 复用 |
| 教务接口有频率限制/封禁 | 请求克制 + 本地缓存为主、联网刷新为辅 |
| 学校升级接口导致功能失效 | 接口层集中封装（对齐 wzu-assistant 的 api-schema.json 做法），单点修复 |
| C 盘剩余空间不足 | AS 与 SDK 全部装 D 盘：Studio → `D:\Android\AndroidStudio`，SDK → `D:\Android\Sdk`，GRADLE_USER_HOME → `D:\Android\.gradle` |

## 七、环境搭建清单（下一步行动）

1. 装 JDK 17（Temurin zip 版解压 D 盘即可，无需安装器）
2. 下载 Android Studio（developer.android.com/studio），安装路径选 D 盘
3. AS 内 SDK Manager：装 SDK Platform 34 + Platform-Tools；SDK 路径改到 `D:\Android\Sdk`
4. 手机：设置 → 关于手机 → 连点版本号开启开发者模式 → 开发者选项打开 USB 调试
5. 数据线连接，AS 中 Run 即可真机安装
