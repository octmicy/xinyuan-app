# M4 设计决策记录（2026-09-04）

本批交付 5 项：今日课程小组件（多尺寸）、课表课程详情弹窗、我的页自定义头像 + GitHub/赞助入口、release 签名、开源上传。关键决策如下。

## 1. 今日课程小组件（Glance）

- **数据链路**：课表页每次成功拉取一周数据（`ScheduleScreen.ensureWeek`）→ `TodayStore.upsertWeek` 原子写 `filesDir/widget_schedule.json`（tmp+rename）→ 触发 `TodayWidget().updateAll`。App 进程被杀后小组件读磁盘渲染。
- **只落盘当前学期**：termKey（如 `2026-3`）不匹配时整体重置，防止在 App 里翻历史学期把小组件带偏。
- **周匹配**：`cxZc` 返回的 `rq` 实测是**区间字符串** `2026-09-07/2026-09-13`（此前文档记为单一周一日期），解析时取 `/` 前半段做周一日期，两种格式兼容。
- **多尺寸**：`SizeMode.Exact` + `LocalSize.current` 按实际尺寸分三档排版（高<160dp 紧凑 / 宽≥250dp且高≥230dp 大盘显示教师）。Manifest 注册三个 receiver（今日课程 / (小) / (大)）给桌面选择器三个预设入口，本质同一 Widget 类。`updatePeriodMillis=30min` 负责跨天翻转。
- **退出登录**：`TodayStore.clear` + 立即重渲染，小组件回到「打开App同步课表」。

## 2. 课表课程详情

点击卡片弹 AlertDialog，配色沿用卡片颜色算法（课程名 hashCode → COURSE_COLORS）。字段：教师/教室(楼·房)/时间(周X 第X-X节)/周次/学分/性质/教学班，空字段自动隐藏。

## 3. 头像

- 默认内置 `avatar_default.png`（用户提供的二次元形象），替代原「名字首字」圆形占位。
- 更换：Photo Picker（`PickVisualMedia`，旧系统自动回退）→ `AvatarStore.save`：采样解码 → 中心裁方 → ≤512px → JPEG(90) 存 `filesDir/avatar.jpg`。属本机偏好，退出登录不清除。

## 4. Release 签名

- keystore：`xyc-release.jks`（RSA2048，有效期 30 年，别名 `xyc`），密码存 `keystore.properties`。两者均已 gitignore，**用户需自行异地备份**（丢失后无法再以同签名发版）。
- `app/build.gradle.kts`：存在 keystore.properties 才挂 signingConfig，否则 release 不签名构建不报错。
